Title: Installing

JShelter can be installed directly through each browser's extension repository:

- [Firefox](https://addons.mozilla.org/firefox/addon/javascript-restrictor/)
- [Chrome and all Chromium-based browsers](https://chrome.google.com/webstore/detail/javascript-restrictor/ammoloihpcbognfddfjcljgembpibcmb) (if in doubt, see [wikipedia](https://en.wikipedia.org/wiki/Chromium_(web_browser)#Browsers_based_on_Chromium) for the list of Chromium-based browsers)

To compile the extension from the source code, see the [building from
scratch](/build/) documentation.
